# Supermarket Scale Project (FPGA)

**Supermarket scale** implemented in **Verilog HDL** for **Artix-7** FPGA (`xc7a100t`), developed with **Xilinx ISE 14.7**.

**Source code:** `Projeto_Balança/`

---

## Requirements

| Requirement | Version | Notes |
|-------------|---------|-------|
| **Xilinx ISE** | 14.7 | IDE for synthesis, implementation, and simulation |
| Artix-7 toolchain | — | Included in ISE for Spartan/Artix families |

ISE 14.7 is legacy Xilinx/AMD software. It requires an academic or evaluation license.

---

## How to open the project

1. Install **Xilinx ISE 14.7**.
2. Open the project file:

```
Projeto_Balança/Projeto_F1v2.xise
```

---

## How to run

### Behavioral simulation

1. In ISE, set a testbench file as the simulation top, for example:
   - `valores_esquema.v` — full schematic test
   - `teste.v`, `testa_modulo_camara.v`, etc. — individual module tests
2. Run **Simulate Behavioral Model**.
3. Analyze waveforms in ISim.

### Synthesis and implementation (FPGA)

1. Set the top schematic: `esquema.sch`
2. Run **Synthesize → Implement → Generate Programming File**
3. Program the FPGA with the generated `.bit` file

## Main modules

| Module | Description |
|--------|-------------|
| `esquema.sch` | Top-level schematic |
| `somador.v` / `somador_preco.v` | Price and weight adders |
| `multiplicador_11_9_bin_11.v` | Multiplier |
| `separador_BCD_8_8.v` / `separador_BCD_4_12.v` | BCD conversion for display |
| `valores_esquema.v` | Full system testbench |
